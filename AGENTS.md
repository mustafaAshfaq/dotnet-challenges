## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues in `mustafaAshfaq/dotnet-challenges`. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical roles, label string equal to the role name (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at each repo root. See `docs/agents/domain.md`.
